# MTGA Builder

A browser app for building **Magic: The Gathering Arena** decks with a focus on
**algorithmic, parameter-driven deck generation**. It supports two formats:

- **Standard** — 60-card constructed, up to 4 copies of a card.
- **Standard Brawl** — 60-card singleton with a legendary commander, restricted
  to the commander's color identity.

The card pool is limited to **Standard-legal, Arena-available** cards and is
refreshed with a single script so it stays current across rotations.

![stack](https://img.shields.io/badge/stack-React%20%2B%20TypeScript%20%2B%20Vite-blue)

## Features

- **Auto-build engine** — generate a full deck from parameters:
  - Format (Standard / Standard Brawl)
  - Mana colors (or auto-pick for constructed)
  - Archetype: **aggro, tempo, midrange, control, ramp, combo**
  - Power bias (card quality vs. archetype fit)
  - Commander selection for Brawl (or auto-pick the best legend in your colors)
- **Card browser** — search by name/text, filter by color, type and mana value,
  with card images and detail view.
- **Deck view** — mana curve, color-pip requirements, role breakdown
  (removal / draw / counters / ramp / sweepers), and live legality validation.
- **Save / load** decks locally (localStorage).
- **MTGA import/export** — copy a deck straight into Arena's importer, or paste
  an Arena decklist back in.

## Keeping the card pool current (rotation)

The app ships with a **bundled snapshot** of the card pool in
`src/data/standard-pool.json` so it works offline and loads instantly. To
refresh it from the live Standard + Arena pool:

```bash
npm run update-pool
```

This queries Scryfall for `legal:standard game:arena -is:alchemy` and rewrites
`standard-pool.json` + `pool-meta.json`. Because Scryfall's legality data is
live, **re-running this after a set rotates automatically yields the new pool —
no code changes required.** Requires network access to `api.scryfall.com`.

> **Note on the bundled sample:** when generated by `scripts/build-fallback.mjs`
> (used when Scryfall is unreachable), the pool is a curated *sample* of real
> Standard-era cards. Set codes / collector numbers are plausible but not
> guaranteed import-accurate. Run `npm run update-pool` on a networked machine
> for the live, import-verified pool. The pool badge in the app shows whether
> the current data is `scryfall` or `fallback`.

## How the generation algorithm works

The engine (`src/engine/`) is a pure, **seeded** (reproducible) pipeline:

1. **Archetype profile** (`archetypes.ts`) sets target land / creature /
   noncreature counts and a target mana curve per archetype.
2. **Scoring** (`scoring.ts`) ranks each candidate card by:
   - *Quality* — inverse of EDHREC rank (a popularity/quality proxy).
   - *Archetype fit* — oracle-text & keyword heuristics (`heuristics.ts`) that
     detect removal, card draw, counters, ramp, sweepers and aggressive
     creatures, weighted per archetype.
   - *Color fit* — penalizes off-color pips.
3. **Slot filling** (`build.ts`) greedily fills the target curve and role split,
   respecting copy limits (4-of for Standard, singleton for Brawl).
4. **Mana base** (`manabase.ts`) counts color pips, adds dual/utility lands from
   the pool, then fills the rest with basics proportional to pip demand.
5. **Validation** (`validate.ts`) enforces deck size, copy limits, color
   identity and format legality.

## MTGA import/export format

Decks export in Arena's text format:

```
Deck
4 Monastery Swiftspear (FDN) 130
2 Get Lost (LCI) 18
22 Mountain
```

Brawl decks lead with a `Commander` section:

```
Commander
1 Sheoldred, the Apocalypse (DMU) 107

Deck
1 Cut Down (DMU) 89
...
```

Double-faced cards export by front-face name; basics export by name only.
The definitive format check is pasting the exported list into **MTG Arena →
Decks → Import** — it should import with zero "card not found" errors.

## Project layout

```
scripts/
  update-pool.mjs      # live Scryfall sync -> bundled JSON
  build-fallback.mjs   # curated offline sample pool
src/
  types/               # Card, Deck, params
  engine/              # archetypes, scoring, heuristics, manabase, build, validate
  io/                  # MTGA export / import
  store/               # zustand state + localStorage saved decks
  components/          # card grid, filters, generator, deck view, modals
  data/                # bundled pool JSON (generated)
```
